## 2. Top 5 Zero-Dep Cycle-17 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 17.1 Reproducible Build & Build-Cache Poisoning Verifier
- **File:** `server/services/reproducibleBuildService.js` · **State:** `data/reproducible-builds.json`
- **Design:** Audits Dockerfiles, lockfiles, and build args before build execution: enforces integer `SOURCE_DATE_EPOCH`, blocks untrusted/unpinned `#syntax=` BuildKit frontends (`CVE-2026-33747`), flags unpinned `curl|bash`/`wget|sh`/`npx`, mutable `:latest` bases, and `.git/config` token persistence (`CVE-2026-133630`), and checks `package-lock.json` `sha512-` integrity coverage (rejecting missing/SHA-1 entries). Emits per-project/branch/lock-hash isolated `--mount=type=cache,id=<scoped>,sharing=locked` + `DiffID` digest-verification args blocking cross-PR cache poisoning (`CVE-2026-93318`/`93326`).
- **Exports:** `auditBuildReproducibility({ dockerfile, lockfileJson, buildArgs, cachePolicy, gitSources })`, `verifyLockfileIntegrity(lockfileJson)`, `buildIsolatedCachePlan({ projectId, branch, lockfileHash, sourceDateEpoch })`, `listBuildAudits(projectId)`.
- **API / MCP:** `POST /api/builds/reproducibility/audit` (`member+`), `POST /api/builds/reproducibility/cache-plan` (`admin`), `GET /api/builds/reproducibility/audits` (`viewer+`) · `culkibo_build_reproducibility` (`audit|verify_lockfile|cache_plan|list`, `dryRun: true` writes).

### 17.2 Preview Synthetic Smoke-Gate & Signed Commit-Status Reporter
- **File:** `server/services/previewGateService.js` · **State:** `data/preview-gates.json`
- **Design:** Blocks untrusted fork PRs (`isFork && !maintainerApproved`) with `FORK_APPROVAL_REQUIRED` before build/secret access; admin approval binds strictly to exact `commitSha` (`dokploy#6010`). Aggregates preview HTTP health, DB migration lint, API contract diff, and synthetic smoke checks into a merge verdict (`success|failure|pending`). Produces GitHub Commit Status payload (`context: 'culkibo/preview-gate'`) signed via Node `crypto` HMAC-SHA256/Ed25519 over `(repo, commitSha, state, targetUrl, checksDigest)` (`coolify#1671`/`#7155`, `dokploy#5856`).
- **Exports:** `evaluatePreviewGate({ projectId, prNumber, commitSha, isFork, maintainerApproved, checks })`, `buildSignedCommitStatus({ repo, commitSha, context, evaluation, signingKey })`, `approveForkPreview({ projectId, prNumber, commitSha, approver })`, `listPreviewGates(projectId)`.
- **API / MCP:** `POST /api/projects/:id/preview-gates/evaluate` (`member+`), `POST /api/projects/:id/preview-gates/approve-fork` (`admin`), `GET /api/projects/:id/preview-gates` (`viewer+`) · `culkibo_preview_gate` (`evaluate|approve_fork|build_status|list`, `dryRun: true` writes).

### 17.3 Surrogate-Key Edge Cache & Stampede Coalescing Coordinator
- **File:** `server/services/edgeCacheService.js` · **State:** `data/edge-cache-keys.json`
- **Design:** **Cures `darkweak/souin#884`:** `parseSurrogateKeys` returns `[]` (NEVER `[""]` or global `SURROGATE_`) on empty/missing headers and caps tags (`<= 64`/entry) with bounded LRU tag index. **Cures `#850`:** singleflight coalescer bounds in-flight leader wait to `backendTimeoutMs` (`5000ms`), falls back to `stale-while-revalidate`, and bypasses coalescing on `Cache-Control: private|no-store` (zero cross-tenant leak). Renders verified tag-purge commands for Caddy/Souin (`Surrogate-Key`), Cloudflare (`Cache-Tag`), and Fastly returning exact `invalidatedKeys.length`.
- **Exports:** `parseSurrogateKeys(headerValue)`, `registerCachedEntry({ cacheKey, surrogateKeys, ttlSec, staleWhileRevalidateSec })`, `purgeBySurrogateKey({ tags, providers, dryRun })`, `evaluateCoalescing({ cacheKey, inFlightCount, backendTimeoutMs, cacheControl })`, `renderCacheControlPolicy(policy)`.
- **API / MCP:** `GET /api/edge/cache/tags` (`viewer+`), `POST /api/edge/cache/purge` (`admin`, `dryRun: true`), `POST /api/edge/cache/coalesce` (`member+`) · `culkibo_edge_cache_purge` (`list_tags|purge|coalesce|render_policy`, `dryRun: true`).

### 17.4 Container Resource Rightsizing & VPA-Lite Recommender
- **File:** `server/services/resourceRightsizerService.js` · **State:** `data/resource-rightsizing.json`
- **Design:** Computes P50/P95/P99 RAM & CPU from telemetry windows (requires `>= 10` samples to reject restart-loop noise). Recommends `ceil(P95 * (1 + headroom))` (`+25%` apps, `+35%` databases) and **forces `+50%` upscale (never shrinks) when `oomCount > 0`**. Quantifies `reclaimableMb` & `wastePct`. **Cures `Dokploy#4050`/`#927`/`#903`:** validates Docker floors (`memoryMb >= 4`, `cpuCores >= 0.001` at 3 decimals) and emits uniform `deploy.resources.limits` + `reservations` Compose patches for both apps and databases.
- **Exports:** `computePercentile(samples, p)`, `recommendContainerResources({ projectId, serviceType, currentMemoryMb, currentCpuCores, samples, oomCount, headroomPct })`, `validateDockerLimits({ memoryMb, cpuCores })`, `buildComposeResourcePatch(recommendation)`, `listRecommendations(projectId)`.
- **API / MCP:** `POST /api/finops/rightsize/analyze` (`member+`), `POST /api/finops/rightsize/patch` (`admin`, `dryRun: true`), `GET /api/finops/rightsize/recommendations` (`viewer+`) · `culkibo_resource_rightsize` (`analyze|build_patch|validate_limits|list`, `dryRun: true`).

### 17.5 Automated Blameless Incident Postmortem & Timeline Correlator
- **File:** `server/services/postmortemCorrelatorService.js` · **State:** `data/postmortems.json`
- **Design:** Merges deploys, OOM forensics, SLO canary rollbacks, alerts, and config-drift events into a chronological CloudEvents-shaped timeline while strictly segregating speculative `chatNotes` into `unverifiedNotes[]` (never polluting `verifiedEvents[]` or `probableRootCause`). Scores pre-incident deploys/drifts in `T-15m..T+0` (`confidence: 0..1`), computes exact `mttdSec` & `mttrSec`, redacts secrets, and exports blameless Markdown/JSON with systemic `actionItems[]`.
- **Exports:** `correlateIncidentTimeline({ incidentId, projectId, windowStart, windowEnd, deploys, oomEvents, canaryRollbacks, alerts, driftEvents, chatNotes })`, `generateBlamelessPostmortem(correlation)`, `exportPostmortemMarkdown(postmortem)`, `listPostmortems(projectId)`.
- **API / MCP:** `POST /api/incidents/postmortems/correlate` (`member+`), `POST /api/incidents/postmortems` (`admin`, `dryRun: true`), `GET /api/incidents/postmortems` (`viewer+`) · `culkibo_incident_postmortem` (`correlate|generate|export_md|list`, `dryRun: true`).

## 3. Section-19 (`19a–19e`) Regressions (`tests/competitor-prs.test.js`)

Offline, deterministic, zero-Docker assertions:
- **`19a` (Build Repro — `CVE-2026-93318`/`33747`/`133630`):** Untrusted `#syntax=evil/fe:latest`, `curl|bash`, missing `SOURCE_DATE_EPOCH`, and lockfile lacking `sha512-` fail `auditBuildReproducibility` (`UNPINNED_FRONTEND`, `PIPE_TO_SHELL`, `MISSING_SOURCE_DATE_EPOCH`, `WEAK_LOCKFILE_HASH`); pinned frontend + `SOURCE_DATE_EPOCH` + `sha512-` pass with isolated `buildIsolatedCachePlan`.
- **`19b` (Preview Gate — `Coolify#1671`/`#7155`, `Dokploy#5856`/`#6010`):** Unapproved fork PR blocks (`FORK_APPROVAL_REQUIRED`); old-SHA approval does NOT authorize new `commitSha`; failed smoke/contract check yields `state: 'failure'` + verifiable HMAC-SHA256 `buildSignedCommitStatus`.
- **`19c` (Surrogate Cache — `Souin#884`/`#850`):** `parseSurrogateKeys('')` returns `[]` (no `SURROGATE_` bucket); `evaluateCoalescing` bypasses `Cache-Control: private` & bounds wait `<= backendTimeoutMs`; `purgeBySurrogateKey({ tags: ['product-42'], dryRun: false })` evicts `>= 1` entry.
- **`19d` (Rightsizer — `Dokploy#4050`/`#927`/`#903`, Goldilocks):** 2048 MB app at P95 256 MB recommends shrink (`reclaimableMb > 1400`) while `oomCount: 2` forces `+50%` upscale; `validateDockerLimits` rejects `<4MiB` RAM & `<0.001` CPU; `buildComposeResourcePatch` emits `deploy.resources.limits` for `database`.
- **`19e` (Postmortem — `IncidentFox`/`OpenSRE`):** `correlateIncidentTimeline` links `T-4m` deploy before OOM + rollback as top `probableRootCause` (`confidence >= 0.8`), computes exact `mttdSec`/`mttrSec`, isolates `chatNotes` in `unverifiedNotes[]`, and exports blameless Markdown.
