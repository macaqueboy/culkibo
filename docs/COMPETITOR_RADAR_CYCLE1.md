### 5 Exact Zero-Dep (`ROOT_DEPS=6`) Pioneering Designs for Cycle 1 & Cycle 2

#### Breakthrough 1 — **Culkibo SmartPack** *(Railpack + `zstd:chunked` DNA → Cycle 2)*
- **Target module:** `server/services/smartPackBuilder.js` (wired into `deployManager.js`).
- **Zero-dep design:**
  1. **Deterministic `build-plan.json` preview:** Before building, statically inspect repo (`package.json`, `pnpm-lock.yaml`, `turbo.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`, `composer.json`, `build.zig`, `Procfile`) with pure Node `fs` (no Nix/Go binary required) and emit an auditable JSON plan users/AI can inspect or override.
  2. **Implicit `.dockerignore` Guard (fixes Railpack v0.43 & `#57`):** When a repo lacks `.dockerignore`, generate an ephemeral build-context ignore list excluding `.git`, `node_modules`, `.venv`, `venv`, `target`, `.next/cache` so context upload stays `< 2 MB` instead of 800 MB.
  3. **BuildKit Framework Cache Mounts + Cgroup Caps:** Emit `# syntax=docker/dockerfile:1` with `--mount=type=cache,id=ckb-${projectId}-npm,target=/root/.npm` (plus `.turbo`, `pip`, `cargo`, `go/pkg/mod`) and enforce host-aware `--memory` / `--cpus` limits on `docker buildx build` so a Vite/Next.js build never OOM-kills production containers on a 1 GB VPS.
  4. **Modern OCI `zstd` / `zstd:chunked` Export Toggle:** Pass `--output type=image,compression=zstd,oci-mediatypes=true` (and optional `compression=zstd,force-compression=true` / `estargz` when containerd remote snapshotter is detected) for 2–4× faster cold pulls and smaller local layer storage.
- **Why 500% ahead:** Zero extra runtime binaries, inspectable by MCP agents (`dryRun`), and immune to Coolify/Dokploy Nixpacks OOM build spikes.

#### Breakthrough 2 — **Culkibo DirectPush (`culkibo pussh`)** *(Unregistry DNA → Cycle 2)*
- **Target module:** `server/services/directPushRegistry.js` + `bin/culkibo.js pussh` (reusing `serverFleetManager.js` SSH tunnels).
- **Zero-dep design:**
  1. Open a reverse SSH tunnel (`ssh -N -R 127.0.0.1:<ephemeralPort>:127.0.0.1:<localPort>`) using Culkibo's existing zero-shell `serverFleetManager.js` ControlMaster (`StrictHostKeyChecking=yes` + TOFU).
  2. Run a tiny (~250-LOC) pure Node `http` **OCI Distribution v2** handler on loopback that checks which layer digests (`sha256:...`) already exist on the remote Docker host (`HEAD /v2/<name>/blobs/<digest>` backed by remote `docker inspect`/layer cache) and streams **only missing layers** over the SSH tunnel with `crypto.createHash('sha256')` integrity verification and Node `zlib` compression.
  3. Remote daemon pulls `127.0.0.1:<ephemeralPort>/<app>:<release>` and tags it locally, then tunnel & loopback registry tear down immediately.
- **Why 500% ahead:** **Zero Docker Hub, zero GHCR tokens, zero registry egress fees, zero exposed ports**, and 5–10× faster multi-VPS deploys than `docker save | ssh docker load` (which re-uploads the entire base OS every deploy!).

#### Breakthrough 3 — **Culkibo EdgeTunnel (`culkibo-tunnel`)** *(Pangolin/Newt + Pingora Drain DNA → Cycle 2)*
- **Target module:** `server/services/edgeTunnelService.js` + `bin/culkibo.js tunnel-agent` (using existing `ws` in `ROOT_DEPS=6` + native `node:net`/`node:crypto`).
- **Zero-dep design:**
  1. **Sovereign CGNAT Tunnel (Zero Cloudflare Lock-In):** Deploy a tiny outbound Node connector (`culkibo tunnel-agent --hub wss://vps.example.com --token <scoped>`) behind any home router, office NAT, or CGNAT. It maintains an outbound TLS WebSocket with multiplexed binary frames (`[streamId:u32][flags:u8][payload]` — reusing `liveSyncEngine.js`'s zero-copy buffer framing pattern!).
