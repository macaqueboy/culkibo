## 2. Top 5 Zero-Dep Cycle-24 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 24.1 SSRF IPv6/NAT64 Unwrapper, DNS-Rebind & Redirect-Hop Firewall
- **File:** `server/services/egressSsrfFirewallService.js` · **State:** `data/egress-ssrf-firewall.json`
- **Design:** **Cures `CVE-2026-44492`/`54272`/`27826`:** normalizes decimal (`2130706433`), octal (`0177.0.0.1`), hex, IPv4-mapped IPv6 (`::ffff:169.254.169.254` / `::ffff:a9fe:a9fe`), NAT64 (`64:ff9b::/96`), and 6to4 (`2002::/16`) back to canonical IPv4 before checking RFC 1918, loopback, link-local IMDS (`169.254.169.254`), and Docker bridge (`172.17.0.1`) blocklists (`SSRF_MAPPED_IPV6_BLOCKED`, `SSRF_OBFUSCATED_IP_BLOCKED`, `SSRF_METADATA_BLOCKED`). Detects TTL=0 DNS rebinding when `resolvedIps` shift across checks (`DNS_REBIND_TOCTOU_DETECTED`), inspects every `3xx` `redirectHops[]` target (`SSRF_REDIRECT_HOP_BLOCKED`), and enforces IMDSv2 hop-limit `1`.
- **Exports:** `normalizeHostToCanonicalIp(host)`, `evaluateEgressRequest({ url, resolvedIps, dnsTtlSec, redirectHops, imdsVersion, pinResolvedIp })`, `listEgressSsrfAudits()`.
- **API / MCP:** `POST /api/security/egress-ssrf/evaluate` (`member+`), `GET /api/security/egress-ssrf/audits` (`viewer+`) · `culkibo_egress_ssrf_firewall` (`evaluate|normalize_ip|list`, `dryRun: true` writes).

### 24.2 SBOM Release-Diff & OpenVEX Exploitability Triage Gate
- **File:** `server/services/vexSbomTriageService.js` · **State:** `data/vex-sbom-triage.json`
- **Design:** Compares baseline vs candidate CycloneDX/SPDX component lists by `purl` (`added[]`, `removed[]`, `upgraded[]`, `downgraded[]`) catching unexpected new packages & version downgrades (`SBOM_VERSION_DOWNGRADE`, `SBOM_NEW_VULNERABLE_COMPONENT`). Applies **OpenVEX `v0.2.0`** statements validating required CISA justification (`vulnerable_code_not_in_execute_path`, `component_not_present`, `inline_mitigations_already_exist`) — rejecting `not_affected` claims missing justification (`VEX_MISSING_JUSTIFICATION`) while suppressing verified non-exploitable CVEs to compute true `actionableCves[]` & noise-reduction %.
- **Exports:** `VALID_VEX_JUSTIFICATIONS`, `diffSbomComponents({ baseComponents, nextComponents })`, `applyVexTriage({ findings, vexStatements })`, `evaluateReleaseSbomGate({ projectId, baseComponents, nextComponents, findings, vexStatements, dryRun })`, `listVexTriageRuns(projectId)`.
- **API / MCP:** `POST /api/supply-chain/vex-triage/evaluate` (`member+`), `POST /api/supply-chain/vex-triage/diff` (`member+`), `GET /api/supply-chain/vex-triage/history` (`viewer+`) · `culkibo_vex_sbom_triage` (`evaluate|diff_sbom|list`, `dryRun: true` writes).

### 24.3 HTTP/3 (`QUIC`) UDP-443, `rmem_max` & RFC 8470 `0-RTT` Guard
- **File:** `server/services/http3QuicGuardService.js` · **State:** `data/http3-quic-guard.json`
- **Design:** **Cures `Caddy#7481`, `CVE-2024-39321`/`CVE-2026-88878` & enforces RFC 8470:** rejects non-idempotent methods (`POST`/`PUT`/`PATCH`/`DELETE`) carrying `Early-Data: 1` with HTTP `425 Too Early` (`HTTP3_0RTT_REPLAY_RISK`), audits VPS host readiness (`udp443Open: false` while `altSvcAdvertised: true` -> `HTTP3_ALT_SVC_BLACKHOLE`, Linux `rmemMaxBytes < 2500000` -> `QUIC_UDP_BUFFER_UNDERSIZED`, Docker `mtu < 1280` -> `QUIC_MTU_FRAGMENTATION`, missing HTTP/3 `readTimeoutSec` -> `HTTP3_MISSING_READ_TIMEOUT`), and emits hardened Caddy `servers { protocols h1 h2 h3 }` + `sysctl` block.
- **Exports:** `evaluateZeroRttRequest({ method, earlyDataHeader, idempotentOverride })`, `auditHttp3Readiness({ udp443Open, altSvcAdvertised, rmemMaxBytes, wmemMaxBytes, allow0Rtt, readTimeoutSec, bridgeMtu })`, `renderHardenedHttp3Config(opts)`, `listHttp3Audits()`.
- **API / MCP:** `POST /api/edge/http3-guard/audit` (`member+`), `POST /api/edge/http3-guard/zero-rtt` (`member+`), `GET /api/edge/http3-guard/audits` (`viewer+`) · `culkibo_http3_quic_guard` (`audit|eval_0rtt|render_config|list`, `dryRun: true` writes).

### 24.4 Database Redundant-Index, Unindexed-FK & `INT4` Overflow Auditor
- **File:** `server/services/dbSchemaHygieneService.js` · **State:** `data/db-schema-hygiene.json`
- **Design:** Audits Postgres catalog metadata (`tables[]`, `indexes[]`, `foreignKeys[]`): flags `INT4`/`SERIAL` PKs with `maxId >= 1_500_000_000` (`INT4_PK_OVERFLOW_IMMINENT`, >70% of `2,147,483,647`), child foreign keys lacking a matching leftmost index (`UNINDEXED_FOREIGN_KEY_LOCK`), `ON DELETE CASCADE` on protected audit/billing tables (`DANGEROUS_FK_CASCADE`), exact/prefix redundant indexes (`idx(a)` shadowed by `idx(a,b)` -> `REDUNDANT_PREFIX_INDEX`), and tables lacking primary keys (`MISSING_PRIMARY_KEY`). Emits online `CREATE INDEX CONCURRENTLY` / `DROP INDEX CONCURRENTLY` / `ALTER COLUMN ... TYPE BIGINT` SQL.
- **Exports:** `auditDatabaseSchema({ databaseName, tables, indexes, foreignKeys })`, `renderSchemaRemediationSql(audit)`, `listSchemaHygieneAudits(databaseName)`.
- **API / MCP:** `POST /api/db/schema-hygiene/audit` (`member+`), `POST /api/db/schema-hygiene/sql` (`admin`, `dryRun: true`), `GET /api/db/schema-hygiene/audits` (`viewer+`) · `culkibo_db_schema_hygiene` (`audit|render_sql|list`, `dryRun: true` writes).

### 24.5 Dual-Window Zero-Downtime Secret Rollover & Stale-Env Verifier
- **File:** `server/services/zeroDowntimeRotationService.js` · **State:** `data/zero-downtime-rotation.json`
- **Design:** **Cures `Dokploy#4833` & `Coolify#4181`/`#6276`:** stores **key-version hashes ONLY** (zero raw secrets persisted!). Blocks single-key in-place rotation when `encryptedPayloadsCount > 0 && !multiKeyRingEnabled` (`SINGLE_KEY_ROTATION_ORPHAN_RISK`), detects containers running stale env hashes across fleet nodes (`STALE_ENV_CONTAINER_DRIFT`) or mounted `.env` overwrite conflicts (`ENV_FILE_MOUNT_CONFLICT`), and generates a verified 4-phase rollover state machine (`ADD_SECONDARY_KEY -> ROLL_DUAL_READERS -> PROMOTE_WRITER -> REVOKE_OLD_AFTER_TTL`) guaranteeing zero dropped sessions or orphaned secrets.
- **Exports:** `auditRotationSafety({ secretName, multiKeyRingEnabled, encryptedPayloadsCount, activeSessionTtlSec, desiredRevokeAfterSec, containerEnvHashes, expectedEnvHash, mountedEnvConflict })`, `planDualKeyRollover({ projectId, secretName, currentKeyVersion, nextKeyVersion, sessionTtlSec, dryRun })`, `listRotationPlans(projectId)`.
- **API / MCP:** `POST /api/security/rotation-plan/audit` (`member+`), `POST /api/security/rotation-plan/create` (`admin`, `dryRun: true`), `GET /api/security/rotation-plan/list` (`viewer+`) · `culkibo_secret_rotation_planner` (`audit|plan|list`, `dryRun: true` writes).
