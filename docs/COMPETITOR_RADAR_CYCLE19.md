## 2. Top 5 Zero-Dep Cycle-20 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 20.1 Reverse-Proxy Trust Boundary, `forward_auth` & Smuggling Guard
- **File:** `server/services/proxyTrustGuardService.js` · **State:** `data/proxy-trust-guard.json`
- **Design:** **Cures `CVE-2026-30851`/`54764`/`88008`/`71324` & `caddy#6783`:** sanitizes inbound requests against explicit `trustedProxyCidrs` — strips client-forged `X-Forwarded-{For,Proto,Port,Host}` & dash/underscore identity header variants (`X-Remote-User`/`X_Remote_User`/`X.Authenticated.User`) whenever source IP is untrusted or auth server omits them (`FORWARD_AUTH_SPOOF_BLOCKED`). Rejects cleartext `Upgrade: h2c` / `HTTP2-Settings` smuggling (`H2C_SMUGGLE_BLOCKED`), `CONNECT` with body on shared HTTP/1.1 pools (`CONNECT_DESYNC_BLOCKED`), and dual `Content-Length` + `Transfer-Encoding` (`TE_CL_SMUGGLE`). Emits hardened Caddy `trusted_proxies` + `forward_auth` header-strip snippet.
- **Exports:** `evaluateProxyRequest({ remoteIp, method, headers, hasBody, upstreamHttpVersion, trustedProxyCidrs, authCopyHeaders })`, `resolveTrustedClientIp({ remoteIp, xForwardedFor, trustedProxyCidrs })`, `renderHardenedProxyTrustBlock(policy)`, `upsertProxyTrustPolicy(policy)`.
- **API / MCP:** `POST /api/edge/proxy-trust/evaluate` (`member+`), `POST /api/edge/proxy-trust/policy` (`admin`, `dryRun: true`), `GET /api/edge/proxy-trust/policy` (`viewer+`) · `culkibo_proxy_trust_guard` (`evaluate|set_policy|render_caddy`, `dryRun: true` writes).

### 20.2 Valkey / Redis Persistence, Eviction & Hot-Key Guard
- **File:** `server/services/valkeyGuardService.js` · **State:** `data/valkey-guard.json`
- **Design:** Audits Valkey 8/9 & Redis configs + host kernel flags: flags `overcommitMemory !== 1` (`BGSAVE_FORK_OOM_RISK`), `thpEnabled !== 'never'` (`THP_COW_AMPLIFICATION`), `maxmemoryMb > hostRamMb * 0.75` (`INSUFFICIENT_FORK_HEADROOM`), workload-vs-eviction mismatches (`workload === 'queue' && evictionPolicy !== 'noeviction'` -> `QUEUE_SILENT_JOB_EVICTION`; `workload === 'cache' && evictionPolicy === 'noeviction'` -> `CACHE_OOM_OUTAGE`), TTL-less key bloat (`noTtlPct > 40%`), and hot-key skew (`topKeyTrafficPct > 20%`). Renders tuned `valkey.conf` + `sysctl` remediation block.
- **Exports:** `auditValkeyConfig({ projectId, workload, hostRamMb, maxmemoryMb, evictionPolicy, overcommitMemory, thpEnabled, appendonly, noTtlPct, topKeyTrafficPct })`, `renderHardenedValkeyConfig(opts)`, `listValkeyAudits(projectId)`.
- **API / MCP:** `POST /api/db/valkey-guard/audit` (`member+`), `POST /api/db/valkey-guard/render` (`admin`, `dryRun: true`), `GET /api/db/valkey-guard/audits` (`viewer+`) · `culkibo_valkey_guard` (`audit|render_config|list`, `dryRun: true` writes).

### 20.3 EOL Base-Image, Runtime Patching (`copa`) & Distroless Advisor
- **File:** `server/services/baseImageHardenerService.js` · **State:** `data/base-image-hardener.json`
- **Design:** Parses `FROM`/`USER`/`RUN` lines & optional Trivy JSON reports: flags EOL bases (`node:16`/`18`, `python:3.8`/`3.9`, `debian:buster`/`bullseye`, `alpine:3.18`, `ubuntu:20.04` -> `EOL_BASE_IMAGE`), root final stages (`ROOT_USER_FINAL_STAGE`), mutable tags without `@sha256:` (`UNPINNED_BASE_TAG`), and shell/pkg-manager bloat in prod stages. Recommends concrete hardened Distroless/Wolfi multi-stage replacements (`read_only: true`, non-root UID `65532`) and generates `copa` thin-patch plans from OS CVE counts without full rebuilds.
- **Exports:** `EOL_BASE_CATALOG`, `auditDockerfileHardening({ projectId, dockerfile, trivySummary, readOnlyRootfs })`, `planCopaThinPatch({ imageRef, osCves, dryRun })`, `listHardeningAudits(projectId)`.
- **API / MCP:** `POST /api/builds/base-hardener/audit` (`member+`), `POST /api/builds/base-hardener/copa-plan` (`admin`, `dryRun: true`), `GET /api/builds/base-hardener/audits` (`viewer+`) · `culkibo_base_image_hardener` (`audit|copa_plan|list`, `dryRun: true` writes).

### 20.4 Backup Envelope Key-Rotation & S3 WORM Object-Lock Verifier
- **File:** `server/services/wormBackupCryptoService.js` · **State:** `data/worm-backup-crypto.json`
- **Design:** **Cures `Coolify#12211`/`#4774` & `Restic#5411`/`#3491`:** verifies S3 WORM backup targets enforce `objectLockMode` (`COMPLIANCE|GOVERNANCE`), `retentionDays >= 7`, non-streaming `Content-MD5` integrity (`MISSING_CONTENT_MD5_WORM`), split non-WORM `locks/` prefix (`WORM_LOCK_PREFIX_CONFLICT`), and escrowed instance master key (`APP_KEY_ESCROW_MISSING`). Implements pure-Node `crypto` **AES-256-GCM envelope encryption** (`wrapBackupKey` / `rotateBackupKek`) re-wrapping DEKs under a new KEK version (`kekVersion++`) in milliseconds without re-uploading multi-GB archives (never persists raw key material!).
- **Exports:** `auditWormBackupPolicy({ bucket, objectLockMode, retentionDays, streamingPipeNoMd5, resticLocksInWormPrefix, keyEscrowVerified })`, `wrapBackupKey({ dekHex, kekHex, kekVersion })`, `rotateBackupKek({ envelope, oldKekHex, newKekHex, newKekVersion })`, `verifyEnvelopeUnwrap({ envelope, kekHex })`, `listWormAudits()`.
- **API / MCP:** `POST /api/backups/worm-crypto/audit` (`member+`), `POST /api/backups/worm-crypto/rotate-kek` (`admin`, `dryRun: true`), `GET /api/backups/worm-crypto/audits` (`viewer+`) · `culkibo_worm_backup_crypto` (`audit|rotate_kek|list`, `dryRun: true`).

### 20.5 Zero-Trust MCP Tool-Poisoning & Rug-Pull Manifest Guard
- **File:** `server/services/mcpPoisonGuardService.js` · **State:** `data/mcp-poison-guard.json`
- **Design:** **Cures `CVE-2025-54136` ("MCPoison"):** computes canonical SHA-256 hashes over every MCP tool's `(name, description, inputSchema, command)` and pins approved manifests (`pinManifest`). Re-verifies manifests on every invocation/reload, blocking any post-approval mutation (`MCP_RUG_PULL_DETECTED`). Scans tool descriptions & tool outputs for hidden prompt-injection tags (`<IMPORTANT>`, `ignore previous instructions`, covert `.ssh`/`.env` exfil instructions, invisible Unicode Tag runes `U+E0000..U+E007F` -> `MCP_TOOL_POISONING_DETECTED`), and verifies role-to-tool least-privilege scopes (`EXCESSIVE_TOOL_SCOPE`).
- **Exports:** `hashToolDefinition(toolDef)`, `pinToolManifest({ serverId, tools, approver, dryRun })`, `verifyToolManifest({ serverId, tools })`, `scanToolPoisoning({ text, source })`, `auditAgentToolScope({ role, allowedTools, requestedTools })`.
- **API / MCP:** `POST /api/mcp/poison-guard/pin` (`admin`, `dryRun: true`), `POST /api/mcp/poison-guard/verify` (`member+`), `POST /api/mcp/poison-guard/scan` (`member+`), `GET /api/mcp/poison-guard/manifests` (`viewer+`) · `culkibo_mcp_poison_guard` (`pin|verify|scan|audit_scope`, `dryRun: true` writes).

## 3. Section-22 (`22a–22e`) Regressions (`tests/competitor-prs.test.js`)

Offline, deterministic, zero-Docker assertions:
- **`22a` (Proxy Trust & Smuggling — `CVE-2026-30851`/`54764`/`88008`/`71324`):** Untrusted client sending `X-Remote-User: admin` + `X_Remote_User: root`, `Upgrade: h2c`, and `CONNECT` with body on HTTP/1.1 upstream blocks (`FORWARD_AUTH_SPOOF_BLOCKED`, `H2C_SMUGGLE_BLOCKED`, `CONNECT_DESYNC_BLOCKED`); `resolveTrustedClientIp` ignores client-spoofed left-most `X-Forwarded-For`.

- **`22c` (Base Hardener — `copa`/Wolfi/Distroless):** Dockerfile with `FROM node:18`, `USER root`, and `readOnlyRootfs: false` flags `EOL_BASE_IMAGE`, `UNPINNED_BASE_TAG`, and `ROOT_USER_FINAL_STAGE`; digest-pinned `cgr.dev/chainguard/node@sha256:...` + `USER 65532` passes; `planCopaThinPatch` defaults `dryRun: true`.
