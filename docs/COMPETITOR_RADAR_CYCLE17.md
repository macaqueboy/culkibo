## 2. Top 5 Zero-Dep Cycle-18 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 18.1 DB Query-Plan & Pool Exhaustion Regression Guard
- **File:** `server/services/queryPlanGuardService.js` · **State:** `data/query-plan-guard.json`
- **Design:** Recursively walks Postgres `EXPLAIN (ANALYZE, FORMAT JSON)` trees flagging `Seq Scan` exceeding `tableRowThreshold` (`10000`) or `costThreshold`, `>10x` estimated-vs-actual row skew (stale `ANALYZE`), and `Sort` spilling to disk (`Sort Space Type: Disk`). `detectNPlusOne` normalizes parameterized query traces to catch `>= 20` repeated single-row lookups per request. `auditPoolBudget` enforces `replicas * poolSizePerReplica <= maxConnections - reservedSuperuser` (`pgbouncer` transaction-mode prepared-statement check + mandatory `idleTimeoutSec > 0`, curing Prisma 7 leaks).
- **Exports:** `analyzeExplainPlan({ planJson, sql, tableRowThreshold, costThreshold })`, `auditPoolBudget({ maxConnections, reservedSuperuser, replicas, poolSizePerReplica, pgbouncerMode, idleTimeoutSec })`, `detectNPlusOne(queryTrace)`, `evaluateDbCutoverGate({ projectId, planJson, poolConfig, queryTrace })`, `listQueryGuardHistory(projectId)`.
- **API / MCP:** `POST /api/db/query-guard/analyze` (`member+`), `POST /api/db/query-guard/pool-audit` (`member+`), `GET /api/db/query-guard/history` (`viewer+`) · `culkibo_query_plan_guard` (`analyze|pool_audit|n_plus_one|history`, `dryRun: true` writes).

### 18.2 Container Network Micro-Segmentation & Lateral-Movement Compiler
- **File:** `server/services/netSegCompilerService.js` · **State:** `data/network-segmentation.json`
- **Design:** **Cures `Dokploy#2798`/`#2987`:** audits Docker/Compose network graphs for flat-bridge lateral paths where public/ingress frontend containers share a bridge with `database`/`cache` services (`LATERAL_DB_EXPOSURE`, `UNISOLATED_DATA_TIER`). Compiles least-privilege segmented bridges: `edge_ingress` (proxy + frontend only), `app_internal` (`internal: true`, frontend -> API), and per-DB `data_<db>` (`internal: true`, authorized API/worker -> DB only — zero direct frontend-to-DB reachability, zero broken project DB links).
- **Exports:** `compileSegmentationPolicy({ projectId, services, allowedEdges, ingressServices })`, `auditLateralMovement({ services, networks, sharedNetworkName })`, `renderComposeNetworks(policy)`, `listSegmentationPolicies(projectId)`.
- **API / MCP:** `POST /api/security/netseg/audit` (`member+`), `POST /api/security/netseg/compile` (`admin`, `dryRun: true`), `GET /api/security/netseg/policies` (`viewer+`) · `culkibo_netseg_policy` (`audit|compile|render_compose|list`, `dryRun: true`).

### 18.3 Security Patch & Transitive Dependency Upgrade Planner
- **File:** `server/services/depUpgradePlannerService.js` · **State:** `data/dep-upgrade-plans.json`
- **Design:** Scores direct & transitive dependency updates into 4 safe lanes: `FAST_TRACK_CVE` (active CVE advisory — **bypasses cooldown**, matching Renovate `vulnerabilityAlerts` & Dependabot security exemption), `COOLDOWN_HOLD` (routine package younger than `minReleaseAgeHours`, default `168h`, or missing publish timestamp — blocks zero-day supply-chain malware), `SAFE_PATCH_MINOR` (aged semver patch/minor grouped for atomic rollout), and `MAJOR_MANUAL_REVIEW` (breaking major bumps isolated with rollback snapshot tag). Generates synced `.npmrc` / `pnpm-workspace.yaml` `minimumReleaseAge` config preventing `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`.
- **Exports:** `planDependencyUpgrades({ projectId, dependencies, advisories, minReleaseAgeHours, nowIso })`, `classifyUpgradeRisk(pkgUpdate)`, `generatePackageManagerCooldown({ manager, minReleaseAgeMinutes, exclude })`, `listUpgradePlans(projectId)`.
- **API / MCP:** `POST /api/supply-chain/upgrades/plan` (`member+`), `POST /api/supply-chain/upgrades/cooldown` (`admin`, `dryRun: true`), `GET /api/supply-chain/upgrades/plans` (`viewer+`) · `culkibo_dep_upgrade_plan` (`plan|cooldown_config|list`, `dryRun: true`).

### 18.4 Streaming Log PII Redaction & GDPR/HIPAA/PCI Scrubber
- **File:** `server/services/logPiiScrubberService.js` · **State:** `data/pii-redaction-ledger.json`
- **Design:** **Cures `otel-contrib#49858`/`#36633`/`#37591`/`#50770` & `vector#6049`:** applies a strictly ordered rule array (`SCRUB_RULES_ORDERED`: JWT/Bearer -> API tokens -> Luhn-verified PCI PANs -> IBAN -> SSN -> Email -> Phone, eliminating Go map-order non-determinism), recursively traverses arbitrary nested JSON, OTLP `span.events[]`, arrays, and numeric/string leaf values (`maxDepth: 16`), and auto-preserves `redaction.*` ledger metadata across chained passes so byte-exact counts (`redactedBytes`, `categoryCounts`, `sha256Pre`/`sha256Post`) remain intact.
- **Exports:** `SCRUB_RULES_ORDERED`, `isValidLuhn(digits)`, `scrubPayload(input, { complianceProfiles, preserveLedgerKeys, maxDepth })`, `scrubStreamChunk(ndjsonChunk, opts)`, `getRedactionLedger(projectId)`.
- **API / MCP:** `POST /api/observability/pii-scrub/test` (`member+`), `POST /api/observability/pii-scrub/policy` (`admin`, `dryRun: true`), `GET /api/observability/pii-scrub/ledger` (`viewer+`) · `culkibo_log_pii_scrubber` (`scrub|set_policy|ledger`, `dryRun: true`).

### 18.5 Graceful Stateful Shutdown & Zero-Drop Queue/Webhook Drain
- **File:** `server/services/gracefulDrainService.js` · **State:** `data/graceful-drains.json`
- **Design:** **Cures `Coolify#8627` & `kamal-proxy` handoff 502s:** audits Dockerfiles & deploy configs for shell-form `CMD`/`ENTRYPOINT` swallowing `SIGTERM` (`PID1_SHELL_WRAPPER`), missing LB drain buffer (`lbDrainDelaySec < healthCheckIntervalSec * 2`), and insufficient `stop_grace_period` for active worker/webhook queues. Orchestrates strict 4-phase state machine (`FLIP_READINESS_503 -> WAIT_LB_DRAIN -> DRAIN_INFLIGHT_JOBS -> EMIT_SIGTERM`) ensuring zero dropped Stripe webhooks/payments before stop.
- **Exports:** `auditShutdownReadiness({ dockerfile, stopGracePeriodSec, lbDrainDelaySec, healthCheckIntervalSec, activeQueueDepth })`, `planOrderedDrain({ projectId, serviceName, inFlightHttp, inFlightJobs, lbDrainDelaySec, maxDrainSec })`, `advanceDrainState(drainId, telemetry)`, `listDrainPlans(projectId)`.
- **API / MCP:** `POST /api/deploys/drain/audit` (`member+`), `POST /api/deploys/drain/plan` (`admin`, `dryRun: true`), `GET /api/deploys/drain/plans` (`viewer+`) · `culkibo_graceful_drain` (`audit|plan|advance|list`, `dryRun: true`).

## 3. Section-20 (`20a–20e`) Regressions (`tests/competitor-prs.test.js`)

Offline, deterministic, zero-Docker assertions:
- **`20a` (Query-Plan & Pool Guard — PgBouncer/Prisma):** `EXPLAIN JSON` with `Seq Scan` (`Actual Rows: 85000`, `Plan Rows: 500`) fails `analyzeExplainPlan` (`SEQ_SCAN_REGRESSION`, `ROW_ESTIMATE_SKEW`); `auditPoolBudget({ maxConnections: 100, replicas: 8, poolSizePerReplica: 20, idleTimeoutSec: 0 })` blocks (`POOL_OVERCOMMIT`, `MISSING_IDLE_TIMEOUT`); 25 identical `SELECT ... WHERE id = $1` traces trigger `N_PLUS_ONE_DETECTED`.
- **`20b` (Network Micro-Seg — `Dokploy#2798`/`#2987`):** Flat shared `dokploy-network` holding `web`, `api`, and `postgres` fails `auditLateralMovement` (`LATERAL_DB_EXPOSURE`); `compileSegmentationPolicy` outputs `internal: true` `data_postgres` reachable ONLY by `api`, isolating `web` from `postgres`.
- **`20c` (Dep Upgrade Planner — `pnpm`/`Renovate`):** 6-hour-old routine minor update is held in `COOLDOWN_HOLD` (`minReleaseAgeHours: 168`), while 2-hour-old critical CVE fix enters `FAST_TRACK_CVE`, and breaking major bump isolates in `MAJOR_MANUAL_REVIEW`.
- **`20d` (Stream PII Scrubber — `OTel#49858`/`#36633`/`#37591`/`#50770`):** Deep OTLP span containing email + Luhn-valid test card inside nested `span.events[]` and numeric SSN field is scrubbed identically across 10 runs (deterministic order), preserves `redaction.count` when re-scrubbed in a 2nd chained pass, and ignores Luhn-invalid 16-digit order IDs.
- **`20e` (Graceful Drain — `Coolify#8627` / `kamal-proxy`):** Shell-form `CMD npm start` with `lbDrainDelaySec: 0` fails `auditShutdownReadiness` (`PID1_SHELL_WRAPPER`, `LB_DRAIN_RACE`); `planOrderedDrain` + `advanceDrainState` refuses `EMIT_SIGTERM` while `inFlightJobs > 0` until jobs drain to `0`.
