## 2. Top 5 Zero-Dep Cycle-22 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 22.1 JWT Algorithm-Confusion, `jku`/`kid` & OIDC Claim Firewall
- **File:** `server/services/jwtOidcFirewallService.js` · **State:** `data/jwt-oidc-firewall.json`
- **Design:** **Cures `CVE-2026-29000`/`33322`/`22817` & `CVE-2025-61152`:** decodes JWT/JWE headers without trusting client `alg`, strictly rejecting `alg: none` (case-insensitive `None`/`nOnE` -> `JWT_ALG_NONE_FORBIDDEN`), JWE-wrapped unsigned inner `PlainJWT` (`JWE_PLAIN_INNER_FORBIDDEN`), symmetric-vs-asymmetric downgrade (`HS256` when `expectedAlgorithms` pins `RS256`/`EdDSA` -> `JWT_ALG_CONFUSION_BLOCKED`), missing JWK `alg` (`JWK_MISSING_EXPLICIT_ALG`), remote `jku`/`x5u` headers (`JWT_JKU_SSRF_BLOCKED`), path/SQLi chars in `kid` (`JWT_KID_INJECTION`), and missing/mismatched `iss`/`aud`/`exp`. Audits OIDC verifier configs for pinned algorithms & rate-limited JWKS refresh.
- **Exports:** `inspectJwtHeaderAndClaims({ token, expectedAlgorithms, expectedIssuer, expectedAudience, nowSec, jwkHasExplicitAlg })`, `auditOidcVerifierConfig({ pinnedAlgorithms, allowAlgNone, allowJkuHeader, sanitizeKid, validateIssAud, jwksRefreshMinIntervalSec })`, `listJwtFirewallAudits()`.
- **API / MCP:** `POST /api/security/jwt-firewall/inspect` (`member+`), `POST /api/security/jwt-firewall/audit-config` (`admin`, `dryRun: true`), `GET /api/security/jwt-firewall/audits` (`viewer+`) · `culkibo_jwt_oidc_firewall` (`inspect|audit_config|list`, `dryRun: true` writes).

### 22.2 Container Heap-Slope, FD-Leak & Event-Loop Lag Guard
- **File:** `server/services/runtimeLeakGuardService.js` · **State:** `data/runtime-leak-guard.json`
- **Design:** Runs ordinary least-squares linear regression (`computeLinearSlope`) over hourly/minute heap & RSS samples to detect monotonic memory leaks (`HEAP_LEAK_SLOPE_HIGH`) and native/external buffer bloat (`NATIVE_RSS_DIVERGENCE`), computing exact `hoursToOom`. Flags missing/oversized V8 `--max-old-space-size` (`V8_HEAP_EXCEEDS_CGROUP`, recommends `floor(containerLimitMb * 0.78)`), open file descriptors `>= 80%` of `ulimit -n` (`FD_EXHAUSTION_EMFILE_RISK`), and GC-driven Event-Loop `p99` lag `>= 100ms` (`EVENT_LOOP_LAG_CRITICAL`). Generates proactive rolling-drain & `--heapsnapshot-signal=SIGUSR2` plans before kernel `SIGKILL`.
- **Exports:** `computeLinearSlope(samples)`, `analyzeRuntimeLeakTelemetry({ projectId, containerLimitMb, configuredMaxOldSpaceMb, heapSamplesMb, rssSamplesMb, openFds, fdLimit, eventLoopLagP99Ms, gcPausePct })`, `buildProactiveDrainPlan(analysis)`, `listLeakAnalyses(projectId)`.
- **API / MCP:** `POST /api/observability/leak-guard/analyze` (`member+`), `POST /api/observability/leak-guard/drain-plan` (`admin`, `dryRun: true`), `GET /api/observability/leak-guard/history` (`viewer+`) · `culkibo_runtime_leak_guard` (`analyze|drain_plan|history`, `dryRun: true` writes).

### 22.3 GraphQL Depth, Fragment-Spread Alias & Introspection Shield
- **File:** `server/services/graphqlDosShieldService.js` · **State:** `data/graphql-dos-shield.json`
- **Design:** **Cures `CVE-2026-47707`/`35441` & `CVE-2025-32031`:** zero-dep GraphQL tokenizer/AST analyzer that **recursively resolves `...FragmentName` spreads** (with cycle & fan-out budget guard!) to count true expanded depth (`GRAPHQL_DEPTH_EXCEEDED`), true expanded alias count (`GRAPHQL_ALIAS_AMPLIFICATION`), exponential fragment fan-out (`GRAPHQL_FRAGMENT_FANOUT_DOS`), HTTP query batching arrays (`batchSize > maxBatchSize` -> `GRAPHQL_BATCH_LIMIT_EXCEEDED`), and production `__schema`/`__type` introspection (`GRAPHQL_INTROSPECTION_BLOCKED`).
- **Exports:** `inspectGraphqlQuery({ query, batchSize, maxDepth, maxAliases, maxFragmentExpansions, maxBatchSize, allowIntrospection, env })`, `upsertGraphqlShieldPolicy(projectId, policy)`, `listGraphqlShieldPolicies()`.
- **API / MCP:** `POST /api/edge/graphql-shield/inspect` (`member+`), `POST /api/edge/graphql-shield/policy` (`admin`, `dryRun: true`), `GET /api/edge/graphql-shield/policies` (`viewer+`) · `culkibo_graphql_dos_shield` (`inspect|set_policy|list`, `dryRun: true` writes).

### 22.4 ACME Rate-Limit Budget, RFC 9773 ARI & TLS Cipher Guard
- **File:** `server/services/acmeTlsBudgetService.js` · **State:** `data/acme-tls-budget.json`
- **Design:** **Cures `Coolify#6800`, `Dokploy#2238` & enforces RFC 9773 ARI:** tracks Let's Encrypt quotas (`certsIssued7d >= 40/50` -> `ACME_WEEKLY_QUOTA_NEAR`, `failedAuthz1h >= 4/5` -> `ACME_AUTHZ_LOCKOUT_RISK`), flags deleted/stale domains lingering in `acme.json` (`STALE_ACME_DOMAINS_DETECTED`), ephemeral non-persistent cert volumes (`EPHEMERAL_CERT_STORAGE`), and missing RFC 9773 `replaces` ARI waivers. `evaluateAriRenewalWindow` selects randomized jittered renewal timestamp inside `[suggestedStart, suggestedEnd]`; `auditTlsCipherPolicy` blocks TLS `1.0`/`1.1` & weak `RC4`/`3DES`/`CBC` ciphers (`WEAK_TLS_VERSION`, `WEAK_CIPHER_SUITE`).
- **Exports:** `auditAcmeRateBudget({ domain, certsIssued7d, failedAuthz1h, staleDomainsInStore, ariSupported, hasPersistentCertVolume, useStagingForDebug })`, `evaluateAriRenewalWindow({ certId, suggestedStartIso, suggestedEndIso, nowIso, replacesCertId })`, `auditTlsCipherPolicy({ minTlsVersion, ciphers })`, `listAcmeBudgetAudits()`.
- **API / MCP:** `POST /api/domains/acme-budget/audit` (`member+`), `POST /api/domains/acme-budget/ari-window` (`member+`), `GET /api/domains/acme-budget/audits` (`viewer+`) · `culkibo_acme_tls_budget` (`audit_budget|ari_window|audit_tls|list`, `dryRun: true` writes).

### 22.5 Archive ("Zip Slip") / Symlink Traversal & Zip-Bomb Firewall
- **File:** `server/services/archiveSlipGuardService.js` · **State:** `data/archive-slip-guard.json`
- **Design:** **Cures `CVE-2026-23745`/`23950` & `CVE-2025-66626`/`62725`:** inspects archive manifests (`.tar`/`.tar.gz`/`.zip`/OCI layers) BEFORE extraction: normalizes Unicode NFC/case-folded paths to catch case-insensitive collision races (`UNICODE_PATH_COLLISION`), rejects `..` parent traversal & absolute paths (`ZIP_SLIP_PATH_TRAVERSAL`), validates BOTH entry path AND symlink/hardlink `linkname` against canonical `targetRoot` (`SYMLINK_ESCAPE_BLOCKED`, `HARDLINK_ESCAPE_BLOCKED`), and rejects decompression bombs where `uncompressedBytes / compressedBytes > maxRatio` (`100`) or total bytes exceed budget (`ZIP_BOMB_DETECTED`).
- **Exports:** `inspectArchiveManifest({ targetRoot, entries, maxRatio, maxTotalUncompressedBytes, allowSymlinks })`, `normalizeSafeEntryPath(targetRoot, entryPath)`, `listArchiveAudits()`.
- **API / MCP:** `POST /api/security/archive-guard/inspect` (`member+`), `GET /api/security/archive-guard/audits` (`viewer+`) · `culkibo_archive_slip_guard` (`inspect|list`, `dryRun: true` writes).
