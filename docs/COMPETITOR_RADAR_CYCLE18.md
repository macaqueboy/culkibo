## 2. Top 5 Zero-Dep Cycle-19 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 19.1 Inbound Webhook Signature Replay & Clock-Skew Firewall
- **File:** `server/services/webhookFirewallService.js` · **State:** `data/webhook-firewall.json`
- **Design:** Supports `stripe`, `github`, `linear`, `slack`, `shopify`, and `svix` (Standard Webhooks). Strictly **fails closed** if secret is empty, missing, or weak/hardcoded (`WEBHOOK_SECRET_UNCONFIGURED`, curing `CVE-2025-61926` & fail-open flaws). Enforces pre-verify body cap (`<= 1 MiB`), computes HMAC-SHA256 over raw byte buffer using length-guarded `crypto.timingSafeEqual`, rejects `|nowSec - timestamp| > maxSkewSec` (`300s`), and canonicalizes Base64/Base64URL/hex signatures before monotonic delivery-ID/signature replay deduplication (`WEBHOOK_REPLAY_DETECTED`, curing `CVE-2026-41351`).
- **Exports:** `SUPPORTED_PROVIDERS`, `canonicalizeSignatureEncoding(sig)`, `verifyInboundWebhook({ provider, rawBody, headers, secret, nowSec, maxSkewSec, routeId })`, `inspectReplayCache(routeId)`, `upsertWebhookFirewallPolicy(routeId, policy)`.
- **API / MCP:** `POST /api/webhooks/firewall/verify` (`member+`), `POST /api/webhooks/firewall/policy` (`admin`, `dryRun: true`), `GET /api/webhooks/firewall/stats` (`viewer+`) · `culkibo_webhook_firewall` (`verify|set_policy|stats`, `dryRun: true` writes).

### 19.2 Container Disk-Pressure, `overlay2` Bloat & Inode Exhaustion Guard
- **File:** `server/services/diskPressureGuardService.js` · **State:** `data/disk-pressure-guard.json`
- **Design:** Tracks **both** block (`df -h`) AND inode utilization (`df -ih`), `overlay2` layer growth, unrotated container JSON logs, and Postgres `pg_wal` segment bloat from inactive replication slots (`INODE_EXHAUSTION_CRITICAL` >= 85% inodes even at low GB, `BLOCK_PRESSURE_CRITICAL` >= 85%, `PG_WAL_SLOT_RUNAWAY`, `UNROTATED_DOCKER_LOGS`, `OVERLAY2_BLOAT`). Emits `/etc/docker/daemon.json` log-rotation config (`max-size: 10m`, `max-file: 3`), `blkio`/volume quota recommendations, and safe remediation steps (`dryRun: true`, curing `Dokploy#4651`/`#2702`/`#2494`).
- **Exports:** `evaluateDiskPressure({ nodeId, blockUsedPct, inodeUsedPct, overlay2Gb, containerLogGb, pgWalGb, inactiveReplicationSlots, diskTotalGb })`, `generateDaemonLogQuotaConfig(opts)`, `planPressureRemediation({ evaluation, dryRun })`, `listDiskPressureReports(nodeId)`.
- **API / MCP:** `POST /api/nodes/disk-pressure/evaluate` (`member+`), `POST /api/nodes/disk-pressure/remediate` (`admin`, `dryRun: true`), `GET /api/nodes/disk-pressure/reports` (`viewer+`) · `culkibo_disk_pressure_guard` (`evaluate|remediate|reports`, `dryRun: true`).

### 19.3 Multi-Region Health-Gated Blue/Green Shift & Sticky-Session Drain
- **File:** `server/services/regionTrafficShiftService.js` · **State:** `data/region-traffic-shifts.json`
- **Design:** **Cures `caddy#7544`/`#7524` & `#6393`/`#8415`:** validates per-region probes (verifying `health_port` host-header & non-redirect 200 status so healthy regions never collapse to `503`), blocks shifting weight to regions with `healthyEndpoints === 0` or error-rate breach (`UNHEALTHY_TARGET_REGION`), enforces progressive blue->green step-ups preserving active sticky sessions via bounded cookie `Max-Age`/`SameSite=Lax`/`HttpOnly` drain window, and emits Caddy `lb_policy cookie` + `health_uri` + `lb_try_duration 5s` + `fail_duration 30s` blocks.
- **Exports:** `evaluateTrafficShift({ projectId, regions, targetGreenWeightPct, stickyCookiePolicy, healthProbes })`, `planBlueGreenShift({ projectId, currentBlueWeightPct, stepPct, stickyMaxAgeSec, failDurationSec })`, `renderCaddyStickyFailoverBlock(config)`, `listTrafficShifts(projectId)`.
- **API / MCP:** `POST /api/edge/traffic-shift/evaluate` (`member+`), `POST /api/edge/traffic-shift/plan` (`admin`, `dryRun: true`), `GET /api/edge/traffic-shift/history` (`viewer+`) · `culkibo_region_traffic_shift` (`evaluate|plan|render_caddy|history`, `dryRun: true`).

### 19.4 Unified Credential, OAuth, GitHub App & API-Key Expiry Watchdog
- **File:** `server/services/credentialExpiryWatchdogService.js` · **State:** `data/credential-watchdog.json`
- **Design:** Persists **metadata only** (zero secret values!). Audits countdowns across `github_app`, `oauth`, `s3_iam`, `db_cert`, `ssh_key`, `acme_cert`, and `api_key` into `EXPIRED`, `CRITICAL (<7d)`, `WARNING (<30d)`, and `HEALTHY` with pre-expiry rotation runbooks. **Cures `Coolify#4702` & `Dokploy#2913`/`#5618`:** flags NTP drift `> 30s` breaking GitHub App JWT `exp` (`CLOCK_SKEW_JWT_FAILURE`), SSH key permissions looser than `0600` (`INSECURE_SSH_KEY_MODE`), ephemeral STS tokens on scheduled backups (`EPHEMERAL_BACKUP_CREDENTIAL`), and install tokens echoed in build logs.
- **Exports:** `registerCredentialMetadata({ id, projectId, kind, label, expiresAtIso, clockSkewSec, permissionsMode, rotationRunbook })`, `auditCredentialExpiries({ projectId, nowIso, warnDays, criticalDays })`, `checkSshAndJwtHygiene({ clockSkewSec, sshKeyMode, usesTempStsToken, logsContainInstallToken })`, `listTrackedCredentials(projectId)`.
- **API / MCP:** `GET /api/security/credentials/watchdog` (`viewer+`), `POST /api/security/credentials/register` (`admin`, `dryRun: true`), `POST /api/security/credentials/audit` (`member+`) · `culkibo_credential_watchdog` (`audit|register|hygiene_check|list`, `dryRun: true`).

### 19.5 Event-Bus / Queue Schema Evolution & Poison-Pill DLQ Gate
- **File:** `server/services/queueSchemaDlqService.js` · **State:** `data/queue-schema-dlq.json`
- **Design:** **Cures Kafka KIP-1034/`UnresolvedUnionException`, BullMQ v5->v6 breaks, & RabbitMQ Quorum DLX storms:** checks JSON-Schema/Avro `BACKWARD`/`FULL` compatibility before worker deploys (`REQUIRED_FIELD_ADDED_NO_DEFAULT`, `FIELD_REMOVED`, `UNION_TYPE_NARROWED`), requires raw opaque byte passthrough on DLQs (blocking `DLQ_SCHEMA_DEADLOCK` when DLQ re-validates broken payloads), and trips poison-pill circuit breaker into bounded quarantine when consecutive deserialization errors exceed threshold.
- **Exports:** `checkEventSchemaEvolution({ format, baseSchema, nextSchema, compatibilityMode })`, `evaluatePoisonPillCircuit({ queueName, totalDelivered, failedCount, consecutivePoisonCount, dlqRawPassthrough, maxRetries })`, `quarantinePoisonMessage({ queueName, messageId, rawPayloadBase64, errorCode, attemptCount, dryRun })`, `listDlqQuarantine(queueName)`.
- **API / MCP:** `POST /api/queues/schema/check` (`member+`), `POST /api/queues/dlq/evaluate` (`member+`), `POST /api/queues/dlq/quarantine` (`admin`, `dryRun: true`), `GET /api/queues/dlq/list` (`viewer+`) · `culkibo_queue_dlq_gate` (`check_schema|evaluate_circuit|quarantine|list`, `dryRun: true`).
