## 2. Top 5 Zero-Dep Cycle-16 Pioneer Service Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 16.1 API Contract & Schema Drift Gate
- **File:** `server/services/apiContractGateService.js` · **State:** `data/api-contracts.json`
- **Design:** Cycle-safe recursive differ for OpenAPI 3.0/3.1 & JSON-Schema (`PATH_REMOVED`, `METHOD_REMOVED`, `REQUIRED_PARAM_ADDED`, `REQUIRED_PROP_ADDED`, `RESPONSE_FIELD_REMOVED`, `TYPE_NARROWED`, `ENUM_VALUE_REMOVED`, `AUTH_REMOVED`) + zero-dep GraphQL SDL lexer (`FIELD_REMOVED`, `ARG_MADE_NON_NULL_WITHOUT_DEFAULT`, `ENUM_VALUE_REMOVED`, `TYPE_KIND_CHANGED`). Enforces `MISSING-VERSION-BUMP` (blocks breaking deploys unless major `info.version` increments or signed `overrideReason`).
- **Exports:** `diffContracts({ format, baseSpec, revisionSpec, policy })`, `saveBaseline({ projectId, format, version, spec })`, `evaluateDeployGate({ projectId, format, revisionSpec, overrideReason })`, `listContractHistory(projectId)`.
- **API / MCP:** `POST /api/contracts/diff` (`member+`), `POST /api/contracts/baseline` (`admin`), `GET /api/contracts/history` (`viewer+`) · `culkibo_api_contract_gate` (`diff|gate|save_baseline|history`, `dryRun: true` writes).

### 16.2 OCI Artifact Signature & SLSA Provenance Verifier
- **File:** `server/services/ociSignatureVerifier.js` · **State:** `data/oci-trust-roots.json`
- **Design:** Rejects mutable tags unless pinned to `@sha256:<64-hex>`. Verifies Sigstore Bundle v0.3 + DSSE PAE via `crypto.verify()` (`ed25519`/`ecdsa-sha256`/`ecdsa-sha384`) and SLSA v1.0/v1.1 (`predicateType`, `builder.id`, `subject[].digest.sha256`). **Cures `CVE-2026-22703`:** Rekor v1/v2 `canonicalizedBody` digest, signature, and pubkey fingerprint MUST match the target artifact digest. Handles Rekor v2 signed timestamps (`cosign#4640`) and OCI 1.1 Referrers `404 -> sha256-<hex>` fallback preserving `tlsVerify` & `artifactType` allowlist.
- **Exports:** `verifyOciBundle({ imageRef, bundle, trustRootId, requiredPredicateType, requireRekor })`, `resolveReferrerStrategy({ referrersStatus, digest, tlsVerify })`, `upsertTrustRoot({ id, name, algorithm, publicKeyPem, allowedBuilders })`, `listTrustRoots()`.
- **API / MCP:** `POST /api/supply-chain/oci-verify` (`member+`), `PUT /api/supply-chain/trust-roots` (`admin`), `GET /api/supply-chain/oci-policies` (`viewer+`) · `culkibo_verify_oci_signature` (`verify|list_roots|upsert_root`, `dryRun: true` writes).

### 16.3 Edge WS / SSE Flood & Slowloris Backpressure Guard
- **File:** `server/services/streamFloodGuardService.js` · **State:** `data/stream-flood-guard.json`
- **Design:** Caps concurrent WS/SSE streams per IP (`maxPerIp: 20`) & project (`maxPerProject: 500`) returning `429`+`Retry-After` / WS `1013` and dropping slow-reader backpressure before OOM. Flags Slowloris (`headerElapsedMs > 5000` or `bytesPerSec < 128`). **Cures `CVE-2026-55458`:** strips RFC 7230 §6.1 hop-by-hop headers (`Proxy-Authenticate`, `Alt-Svc`, `Keep-Alive`, `TE`, `Trailer`, `Transfer-Encoding`, plus `Connection` tokens except `Upgrade`) on `101` upgrades. Emits Caddy `read_timeout 0`, `write_timeout 0`, `flush_interval -1`, `stream_close_delay 30s`, and `< 45s` heartbeats (curing Dokploy `#3033`/`#4202`).
- **Exports:** `evaluateStreamAdmission({ projectId, clientIp, protocol, activePerIp, activeProject, headerElapsedMs, bytesPerSec, bufferedBytes })`, `scrubUpgradeHeaders(headers)`, `generateCaddyStreamBlock(policy)`, `upsertStreamPolicy(projectId, policy)`, `getStreamGuardSummary()`.
- **API / MCP:** `GET /api/edge/stream-guard` (`viewer+`), `POST /api/edge/stream-guard/policy` (`admin`), `POST /api/edge/stream-guard/evaluate` (`member+`) · `culkibo_stream_flood_guard` (`status|evaluate|set_policy|render_caddy`, `dryRun: true` writes).

### 16.4 Zero-Downtime DNS Cutover & TTL Pre-Flight Verifier
- **File:** `server/services/dnsCutoverService.js` · **State:** `data/dns-cutovers.json`
- **Design:** Injectable `dns.promises.Resolver` queries authoritative NSes directly to verify `SOA.serial` & `A`/`AAAA`/`CNAME` convergence and stale `_acme-challenge.<domain>` TXT collisions (`81058`). Matches Cloudflare Anycast CIDRs to report `CLOUDFLARE_PROXY_ACME_CONFLICT` under `http-01`/`tls-alpn-01` (curing Coolify `#6271`/`#11831` & Kamal `#26`, avoiding false "DNS mismatch"). Builds 5-phase TTL-lowering plan (`minPreCutoverWaitSec = max(currentTtlSec, soaRefresh)`).
- **Exports:** `preflightDnsCutover({ domain, targetIpv4, targetIpv6, challengeMode, recordsSnapshot })`, `buildTtlCutoverPlan({ domain, currentTtlSec, targetTtlSec, targetIp, acmeMode })`, `isCloudflareProxyIp(ip)`, `getCutoverStatus(domain)`.
- **API / MCP:** `POST /api/domains/cutover/preflight` (`member+`), `POST /api/domains/cutover/plan` (`admin`), `GET /api/domains/cutover/status/:domain` (`viewer+`) · `culkibo_dns_cutover_plan` (`preflight|plan|status`, `dryRun: true`).

### 16.5 Orphaned PR-Preview Auto-Reaper & Dangling Resource GC
- **File:** `server/services/orphanReaperService.js` · **State:** `data/orphan-reaper.json`
- **Design:** Reads Docker solely via `--format '{{json .}}'` with `shell: false` (immune to Docker 29 `awk` drift, `coolify#12148`). Cross-checks `culkibo.managed`, `culkibo.project`, `culkibo.preview.pr`, and `com.docker.compose.project` labels against active projects/PRs: reaps orphan preview containers/Swarm services (`dokploy#4203`/`#4893`), cascades leaked `-pr-<n>` named volumes (`coolify#11441`), and prunes aged dangling layers/buildx cache while protecting active Compose sidecars (`dokploy#3973`) & `culkibo.protect=true` DB volumes. Defaults `dryRun: true` with byte ledger.
- **Exports:** `scanOrphans({ dockerSnapshot, activeProjects, activePreviews, policy })`, `planReap({ scanResult, maxReapPerRun })`, `executeReap({ plan, dryRun, executor })`, `upsertReaperPolicy(policy)`.
- **API / MCP:** `POST /api/cleanup/orphans/scan` (`viewer+`), `POST /api/cleanup/orphans/reap` (`admin`, `dryRun: true`), `GET /api/cleanup/orphans/policy` (`viewer+`) · `culkibo_orphan_reaper` (`scan|reap|get_policy|set_policy`, `dryRun: true`).

## 3. Section-18 (`18a–18e`) Regressions for `tests/competitor-prs.test.js`
