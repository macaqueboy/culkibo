## 2. Top 5 Zero-Dep Cycle-21 Pioneer Service Blueprints

### 21.1 Browser Security Headers, Strict CSP/SRI & CORS Firewall
- **File:** `server/services/edgeCorsCspService.js` · **State:** `data/edge-cors-csp.json`
- **Design:** **Cures `CVE-2025-34291`/`63388` & `CVE-2026-27579`:** blocks `allowCredentials: true` paired with wildcard `*`, `reflectOrigin: true`, regex suffix traps (`evil-example.com`), or `SameSite=None` without exact origin allowlist (`CORS_WILDCARD_CREDENTIALS`, `CORS_REFLECTED_ORIGIN_CREDENTIALS`). Audits HTTP response headers & third-party `<script>` tags for missing `Strict-Transport-Security`, `COOP`/`COEP`, CSP `'unsafe-inline'`/`'unsafe-eval'` (`CSP_UNSAFE_DIRECTIVE`), and external CDN scripts lacking `integrity="sha384-..."` (`MISSING_SRI_HASH`). Renders Caddy `header` + exact-origin matcher snippet.
- **Exports:** `auditCorsPolicy({ allowedOrigins, allowCredentials, reflectOrigin, sameSiteCookie, probeOrigin })`, `auditSecurityHeaders({ headers, externalScripts })`, `renderHardenedCaddyHeadersBlock(policy)`, `upsertCorsCspPolicy(projectId, policy)`, `listCorsCspPolicies()`.
- **API / MCP:** `POST /api/edge/cors-csp/audit` (`member+`), `POST /api/edge/cors-csp/policy` (`admin`, `dryRun: true`), `GET /api/edge/cors-csp/policies` (`viewer+`) · `culkibo_cors_csp_guard` (`audit|set_policy|render_caddy|list`, `dryRun: true` writes).

### 21.2 PostgreSQL Autovacuum, XID Wraparound & Bloat Guard
- **File:** `server/services/pgVacuumGuardService.js` · **State:** `data/pg-vacuum-guard.json`
- **Design:** Evaluates cluster/table telemetry against Postgres 32-bit wraparound bounds: alerts `WARNING` at `xidAge >= 1_000_000_000` and `CRITICAL` (`XID_WRAPAROUND_IMMINENT`) at `>= 1_500_000_000`, flags `idleInTxSec >= 300` (`IDLE_IN_TX_XMIN_PIN`), missing `idle_in_transaction_session_timeout` (`MISSING_IDLE_TX_TIMEOUT`), `autovacuumDisabledTables.length > 0` (`AUTOVACUUM_DISABLED_TABLE`), `deadTuplePct >= 30` (`TABLE_BLOAT_HIGH`), and inactive slots. Recovery planner strictly emits online `VACUUM VERBOSE` + `pg_terminate_backend` + `idle_in_transaction_session_timeout` SQL — **never `VACUUM FULL`** during wraparound emergencies!
- **Exports:** `auditPgVacuumHealth({ databaseName, xidAge, maxTableXidAge, idleInTxSec, deadTuplePct, autovacuumDisabledTables, inactiveSlots, idleInTxTimeoutMs })`, `planWraparoundRecovery(audit)`, `renderHardenedVacuumSql(opts)`, `listVacuumAudits(databaseName)`.
- **API / MCP:** `POST /api/db/vacuum-guard/audit` (`member+`), `POST /api/db/vacuum-guard/recover-plan` (`admin`, `dryRun: true`), `GET /api/db/vacuum-guard/audits` (`viewer+`) · `culkibo_pg_vacuum_guard` (`audit|recover_plan|render_sql|list`, `dryRun: true` writes).

### 21.3 Monorepo Affected-Graph Selective Builder & Rollout Planner
- **File:** `server/services/monorepoGraphService.js` · **State:** `data/monorepo-graphs.json`
- **Design:** **Cures `Dokploy#5547` & Coolify unordered monorepo deploys:** builds a pure-JS dependency DAG from workspace descriptors (`{ name, dir, deps[], watchPaths[] }`) and maps `changedFiles[]` (even on PR events!) to exact directly-touched + transitive dependent services (`skippedServices[]` saved from needless rebuilds). Runs Kahn's algorithm to detect cycles (`WORKSPACE_CYCLE_DETECTED`) and output ordered `deployWaves[]` (`packages/shared -> api -> web`) plus reverse `rollbackWaves[]` if wave `k` fails.
- **Exports:** `resolveAffectedServices({ workspaces, changedFiles, rootTriggerFiles })`, `computeTopologicalDeployWaves({ workspaces, affectedNames })`, `detectWorkspaceCycles(workspaces)`, `planMonorepoRollout({ projectId, workspaces, changedFiles, dryRun })`, `listMonorepoPlans(projectId)`.
- **API / MCP:** `POST /api/builds/monorepo/affected` (`member+`), `POST /api/builds/monorepo/plan` (`admin`, `dryRun: true`), `GET /api/builds/monorepo/plans` (`viewer+`) · `culkibo_monorepo_graph` (`affected|plan_rollout|check_cycles|list`, `dryRun: true` writes).

### 21.4 Transactional Email Auth (`SPF`/`DKIM`/`DMARC`/`MTA-STS`) Guard
- **File:** `server/services/emailAuthGuardService.js` · **State:** `data/email-auth-guard.json`
- **Design:** **Cures Gmail/Yahoo/Microsoft bulk-sender rejections & `Coolify#4311`:** parses SPF mechanisms (`include`, `a`, `mx`, `ptr`, `exists`, `redirect`) counting DNS lookups (`> 10` -> `SPF_LOOKUP_LIMIT_EXCEEDED` RFC 7208 PermError; `+all` -> `SPF_PERMISSIVE_ALL`). Enforces `dkimBits >= 2048` (`DKIM_KEY_TOO_WEAK`), DMARC presence + `From:` domain alignment (`DMARC_MISSING_OR_UNALIGNED`, warns on `p=none`), `MTA-STS` mode (`enforce` vs `none`), and SMTP port-vs-TLS parity (`port 465 => implicit_tls`, `port 587 => starttls`, `port 25 => BLOCKED_CLOUD_PORT`, curing `Coolify#4311`).
- **Exports:** `auditSpfRecord(spfTxt)`, `auditEmailDeliverability({ domain, fromAddress, spfTxt, dkimBits, dkimSelector, dmarcTxt, mtaStsMode, smtpPort, smtpTlsMode })`, `renderHardenedDnsAuthRecords({ domain, providerInclude, selector, dmarcRua })`, `listEmailAuthAudits(domain)`.
- **API / MCP:** `POST /api/domains/email-auth/audit` (`member+`), `POST /api/domains/email-auth/render` (`admin`, `dryRun: true`), `GET /api/domains/email-auth/audits` (`viewer+`) · `culkibo_email_auth_guard` (`audit|render_dns|list`, `dryRun: true` writes).

### 21.5 Supply-Chain Worm (`Shai-Hulud`/`CHAINDROP`) & `postinstall` Guard
- **File:** `server/services/pkgConfusionGuardService.js` · **State:** `data/pkg-confusion-guard.json`
- **Design:** Guards `package.json`/lockfile graphs against 2025–2026 npm worms & dependency confusion: flags unapproved `preinstall`/`postinstall`/`install` hooks (`UNAPPROVED_LIFECYCLE_SCRIPT`), known Shai-Hulud/CHAINDROP IoC payloads (`setup.mjs`, `math_init.js`, `Math_Symbol.js`, `rm -rf ~`, env/token exfil -> `WORM_IOC_DETECTED`), missing `ignore-scripts=true` (`NPM_SCRIPTS_ENABLED`), unscoped private packages colliding with public registries (`DEPENDENCY_CONFUSION_RISK`), and Levenshtein distance `1..2` typosquats of popular packages (`TYPOSQUAT_SUSPECTED`, e.g., `expres`, `lodahs`). Emits hardened `.npmrc` (`ignore-scripts=true`).
- **Exports:** `levenshteinDistance(a, b)`, `auditPackageSupplyChain({ projectId, packages, internalScopes, allowLifecycleScripts, npmrcIgnoreScripts })`, `scanInstallScriptRisk(scriptBody)`, `generateSafeNpmrc(allowScripts)`, `listPkgGuardAudits(projectId)`.
- **API / MCP:** `POST /api/supply-chain/pkg-guard/audit` (`member+`), `POST /api/supply-chain/pkg-guard/npmrc` (`admin`, `dryRun: true`), `GET /api/supply-chain/pkg-guard/audits` (`viewer+`) · `culkibo_pkg_confusion_guard` (`audit|generate_npmrc|list`, `dryRun: true` writes).
