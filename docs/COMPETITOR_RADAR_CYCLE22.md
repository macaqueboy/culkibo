## 2. Top 5 Zero-Dep Historic Cycle-23 (`200 MCP Tools`) Blueprints

> **Invariants:** `ROOT_DEPS=6` (Node built-ins only), `shell: false`, lazy `require()` (`0 B` boot RSS delta), atomic `0o600` JSON in `CULKIBO_DATA_DIR/data/<name>.json`, plain/`Proto.fn.bind(inst)` exports, RBAC + project ACL, mutating MCP tools default `dryRun: true`.

### 23.1 Next.js / RSC Middleware & SSR Cache-Poisoning Firewall
- **File:** `server/services/ssrEdgeGuardService.js` · **State:** `data/ssr-edge-guard.json`
- **Design:** **Cures `CVE-2025-29927`, `CVE-2025-55182` & `CVE-2025-49005`:** inspects inbound SSR requests & framework versions: strips/blocks client-supplied internal framework headers (`x-middleware-subrequest`, `x-middleware-invoke`, `x-invoke-path`, `x-invoke-query`, `x-nextjs-data` -> `SSR_INTERNAL_HEADER_SPOOF`), validates response `Vary` includes `RSC`, `Next-Router-State-Tree`, and `Next-Router-Prefetch` (`RSC_VARY_HEADER_MISSING`), and flags vulnerable React (`19.0.0`, `19.1.0`, `19.1.1`, `19.2.0` -> `REACT2SHELL_VULNERABLE_VERSION`) & Next.js (`<14.2.25` / `15.0..15.2.2` -> `NEXTJS_MIDDLEWARE_CVE_VERSION`). Emits hardened Caddy `request_header -x-middleware-subrequest` + `header +Vary` block.
- **Exports:** `INTERNAL_SSR_HEADERS`, `evaluateSsrEdgeSecurity({ framework, nextVersion, reactVersion, requestHeaders, responseHeaders })`, `renderHardenedSsrCaddyBlock(opts)`, `listSsrEdgeAudits()`.
- **API / MCP:** `POST /api/edge/ssr-guard/evaluate` (`member+`), `POST /api/edge/ssr-guard/render` (`admin`, `dryRun: true`), `GET /api/edge/ssr-guard/audits` (`viewer+`) · `culkibo_ssr_edge_guard` (`evaluate|render_caddy|list`, `dryRun: true` writes).

### 23.2 Container Registry Pull-Limit & Pull-Through Mirror Guard
- **File:** `server/services/registryMirrorGuardService.js` · **State:** `data/registry-mirror-guard.json`
- **Design:** Audits VPS node pull velocity against Docker Hub (`10/hr` anonymous, `100+/6h` auth) & GHCR limits accounting for multi-arch manifest fan-out (`effectivePulls = pullsPerHour * archMultiplier`): flags `ANONYMOUS_HUB_RATE_LIMIT_RISK`, `SHARED_NAT_QUOTA_EXHAUSTION`, `MISSING_REGISTRY_MIRROR`, and `PLAINTEXT_DOCKER_CONFIG_AUTH`. Generates hardened `/etc/docker/daemon.json` (`registry-mirrors` pointing to local `registry:3` / Culkibo DirectPush + `max-concurrent-downloads`) and jittered deploy pull schedules.
- **Exports:** `auditRegistryPullBudget({ nodeId, registry, authenticated, pullsPerHour, archCount, sharedNatIp, mirrors, plaintextConfigAuth })`, `renderDaemonMirrorConfig({ mirrorUrls, maxConcurrentDownloads })`, `listRegistryMirrorAudits()`.
- **API / MCP:** `POST /api/builds/registry-mirror/audit` (`member+`), `POST /api/builds/registry-mirror/config` (`admin`, `dryRun: true`), `GET /api/builds/registry-mirror/audits` (`viewer+`) · `culkibo_registry_mirror_guard` (`audit|render_config|list`, `dryRun: true` writes).

### 23.3 Session Cookie, Fetch-Metadata (`Sec-Fetch-Site`) & OAuth PKCE Guard
- **File:** `server/services/sessionCsrfGuardService.js` · **State:** `data/session-csrf-guard.json`
- **Design:** **Implements Go 1.25 `CrossOriginProtection` + OAuth 2.1 PKCE (`CVE-2026-26247`):** evaluates mutating HTTP requests (`POST`/`PUT`/`PATCH`/`DELETE`) blocking `Sec-Fetch-Site: cross-site|same-site` (`CSRF_CROSS_ORIGIN_BLOCKED`) or mismatched `Origin` vs `Host` fallback (`CSRF_ORIGIN_MISMATCH`) while allowing safe `GET`/`HEAD`/`OPTIONS`. Audits `Set-Cookie` headers for missing `HttpOnly`, `Secure`, `SameSite=Lax|Strict`, or `__Host-` prefix violations (`COOKIE_MISSING_HTTPONLY`, `COOKIE_HOST_PREFIX_INVALID`). Verifies OAuth 2.1 PKCE strictly enforces `S256` with persisted `code_challenge` & SHA-256 `code_verifier` match (`PKCE_PLAIN_FORBIDDEN`, `PKCE_VERIFIER_MISMATCH`, `OAUTH_STATE_WEAK`).
- **Exports:** `evaluateCrossOriginRequest({ method, secFetchSite, origin, host, trustedOrigins })`, `auditSessionCookie(setCookieHeader)`, `verifyOAuthPkceFlow({ method, codeChallenge, codeVerifier, persistedMethod, state })`, `listSessionCsrfAudits()`.
- **API / MCP:** `POST /api/security/session-csrf/evaluate` (`member+`), `POST /api/security/session-csrf/pkce` (`member+`), `GET /api/security/session-csrf/audits` (`viewer+`) · `culkibo_session_csrf_guard` (`evaluate_csrf|audit_cookie|verify_pkce|list`, `dryRun: true` writes).

### 23.4 SQLite WAL Checkpoint Starvation & Network-FS Corruption Guard
- **File:** `server/services/sqliteWalGuardService.js` · **State:** `data/sqlite-wal-guard.json`
- **Design:** Audits single-VPS SQLite apps (Rails 8 Solid, PocketBase, Uptime Kuma, Litestream): blocks `filesystemType` in `['nfs', 'cifs', 'smb', 'efs']` (`SQLITE_NETWORK_FS_CORRUPTION`), flags `journalMode !== 'wal'` (`SQLITE_NON_WAL_LOCK_RISK`), `busyTimeoutMs < 5000` (`SQLITE_BUSY_TIMEOUT_LOW`), `synchronous === 'off'` (`SQLITE_SYNC_OFF_CORRUPTION`), missing `journal_size_limit` (`SQLITE_UNBOUNDED_WAL`), and WAL bloat (`walSizeMb > dbSizeMb * 2` or `blockedReaders > 0` -> `WAL_CHECKPOINT_STARVATION`). Emits hardened `PRAGMA` bootstrap + safe `PRAGMA wal_checkpoint(TRUNCATE)` SQL.
- **Exports:** `auditSqliteWalHealth({ databaseName, filesystemType, journalMode, synchronous, busyTimeoutMs, journalSizeLimitMb, dbSizeMb, walSizeMb, blockedReaders, foreignKeys })`, `renderHardenedSqlitePragmas(opts)`, `listSqliteWalAudits()`.
- **API / MCP:** `POST /api/db/sqlite-wal/audit` (`member+`), `POST /api/db/sqlite-wal/pragmas` (`admin`, `dryRun: true`), `GET /api/db/sqlite-wal/audits` (`viewer+`) · `culkibo_sqlite_wal_guard` (`audit|render_pragmas|list`, `dryRun: true` writes).

### 23.5 Build-`ARG` / `ENV` Secret Surface & `/run/secrets/` Migrator
- **File:** `server/services/envSecretSurfaceService.js` · **State:** `data/env-secret-surface.json`
- **Design:** **Cures `Dokploy#3347` & `Coolify#10822`:** scans Dockerfiles & Compose definitions (key names ONLY — zero secret values stored!) for sensitive variable patterns (`*_SECRET`, `*_KEY`, `*_TOKEN`, `*_PASSWORD`, `DATABASE_URL`) inside Dockerfile `ARG`/`ENV` (`BUILDKIT_SECRET_IN_ARG_OR_ENV`) or plaintext Compose `environment:` instead of `/run/secrets/` tmpfs mounts (`COMPOSE_SECRET_IN_PLAIN_ENV`). Generates zero-leak `RUN --mount=type=secret,id=<id>` Dockerfile & Compose `secrets:` (`mode: 0400`) migration snippets.
- **Exports:** `auditEnvSecretSurface({ projectId, dockerfile, composeEnvKeys, composeSecretKeys, buildTimeEnvKeys })`, `renderSecretMountMigration({ secretNames })`, `listEnvSurfaceAudits(projectId)`.
- **API / MCP:** `POST /api/security/env-surface/audit` (`member+`), `POST /api/security/env-surface/migrate` (`admin`, `dryRun: true`), `GET /api/security/env-surface/audits` (`viewer+`) · `culkibo_env_secret_surface` (`audit|migrate_snippet|list`, `dryRun: true` writes).
